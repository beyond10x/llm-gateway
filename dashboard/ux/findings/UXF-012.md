The caption reads "3 active sessions → 3 routes; ● input tokens ● output tokens". It does not say
that a dot is one call's tokens (its size is not a token count), that input runs left to right and
output right to left, that a blue thick string is a call in flight and a grey one is only recent
(5 minutes), or what "active" means. The in-flight state of a string is carried by colour and
weight alone. Under reduced motion no dot is drawn at all (review-flow-1280-reduced-dark.png), yet
the caption still lists the input and output keys, so the key names marks the page never shows, and
the panel then carries no token information. Sessions: token-flow, busy. Cost S. One line: add
"blue string: call in flight; dots: tokens of a call, in left to right, out right to left" to the
caption, and drop the dot keys when motion is reduced.
