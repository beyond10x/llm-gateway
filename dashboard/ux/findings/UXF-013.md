(the "output tokens" key drops to a second line) and the panel grows 41 px, pushing the Overview and
every table down (measured from the replay: panel heights 190 then 231, constant after). At 1366 and
1280 the panel stays 230 px, so no shift there. Separately, in idle the panel is a 180 px box with the
single line "No active sessions." (contact-1366x768-light.png, idle) above the Overview and the tables
(heuristic 3: the common state spends the first screen on nothing). Sessions: idle, token-flow at
390x844. Cost S. One line: reserve two caption lines at narrow widths and collapse the empty box to a
single row when there is no session.

Closed in R-04: the counts ("3 active sessions → 3 routes", "no active session") sit on the
heading's line and never wrap, and the colour key below them is the same line in every state, so
the panel has one height per viewport whatever the sessions: in idle, in every state of
token-flow and while a session comes and goes (at 390x844 it grew from 189.6 to 230.6 px before), and
the Overview below it does not move (layout shift 0 at the first-session state, 0.175 before). At
the wider viewports the keys no longer move sideways when the counts appear (layout shift 0.0007 to
0.0069 before). The idle box keeps its height, so the first session does not push the page down;
it says "No active sessions." in words. As a side effect the token-flow layout shift at the gating
viewports fell from 0.059 to 0.043.
