In busy, one page says "streaming" and "waiting-upstream" (lower case, hyphen) next to "waiting for
retry, 24 s left" in the In flight State column, "RUNNING" and "STARTING" in capitals in the pod
State column, and raw header values with underscores in the limit tiles ("allowed_warning",
"out_of_credits", "five_hour"). One concept, state, has three spellings, so a person cannot say the
words back the same way twice. Heuristic 12; related to UXF-006. Sessions: busy, token-flow, errors.
One line: one table of display words for every state value.

Closed in R-06. The document holds one table of display words, `label_maps.state`, and every field
that shows a state reads it: the in-flight state ("waiting for upstream", "waiting for retry" with
"24 s left · attempt 2" as its note), the pod state ("running", "starting"), vLLM ready ("yes",
"no"), a call's and an attempt's status ("ok", "refused", "failed" with the HTTP status as a note),
and the limit status, overage, overage reason and representative claim ("allowed (warning)", "out
of credits", "5-hour window"). The raw value is in the title of each. A raw value the table does
not name (a new pod state) still shows as it is. The heartbeat and the shutdown countdown are
sentences, not state words, and keep their own wording.
