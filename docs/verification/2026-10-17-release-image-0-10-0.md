## Source revision

Both build jobs ran `docker buildx build --build-arg SOURCE_SHA=b392ebcd69cc50b4abb5c95a6dac66d4e77723b0`,
and each build's metadata names `"vcs:revision": "b392ebcd69cc50b4abb5c95a6dac66d4e77723b0"`.
The `Dockerfile` sets `LABEL org.opencontainers.image.revision=$SOURCE_SHA`, so both platform
images carry the tag's commit as their revision label.

## Before the push

The `version-is-new` job ran `docker buildx imagetools inspect ghcr.io/beyond10x/llm-gateway:0.10.0`
before any build and printed `ghcr.io/beyond10x/llm-gateway:0.10.0 is not in the registry yet`;
a run for a version already in the registry fails there and pushes nothing.
