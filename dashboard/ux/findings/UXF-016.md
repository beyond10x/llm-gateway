Introduced by the move to the renderer: R-04's contact sheet reads "1.98k tok/s last 60 s"; R-05 reads
"1.98k tok/slast 60 s" in the Tokens in and Tokens out tiles and "–last 60 s" in idle. In Sessions
the label and the id run into one word, "claude-code3f9a1c0e", "codex8b27d4aa", "curl/8.11c01e5f72"
(the id is smaller mono type, but nothing separates it), and the In flight state note reads
"waiting for retry, 23 s leftattempt 2" as text. A person reading the session name aloud, or copying
it, gets the id as part of it. Heuristics 5 (the id's source is unclear) and 7. Sessions: idle, busy,
token-flow, errors, both themes, every viewport. One line: put the space in the text (a text
interpolation, not template whitespace) and assert the tile and session text.

Closed in R-06. The space before a window, a note and a tag is written as a text interpolation,
which Vue keeps at the start of a conditional template. The regression test reads textContent in
idle, busy and errors: the token tiles read "2.06k tok/s last 60 s" and "– last 60 s", the session
row headers "claude-code 3f9a1c0e", and an in-flight state with its note "… attempt 2".
