With any cache route (scenarios busy, token-flow, errors), the nowrap rows "claude-haiku 98% 1.78M /
1.81M" are wider than the 12rem tile and draw over the Throughput tile at 1366x768 and 1280x720 in
both themes. At 390x844 (measured only) the subscription-limit header values (`dl.headers dd`) also
run past their list. There is no horizontal document scroll; the overflow is inside the page.
Fixed when no element runs past its box at the gating viewports; the fix removes the
`gate1-overflow` entry in `e2e/known-failures.ts`.
