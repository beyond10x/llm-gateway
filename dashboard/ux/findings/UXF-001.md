A person who wants the dark theme on a light system (or the reverse) cannot get it. The harness looks
for a radiogroup, combobox, switch or button named theme, dark, light or appearance and found none in
any scenario, viewport or theme. Fixed when a toggle in the header sets the theme in every replay; the
fix removes the `theme-toggle` entry in `e2e/known-failures.ts`.

Corrected after the R-05 rating: severity S2 becomes S3. Checked: without the toggle the page still
follows the system colour scheme (`data-theme` "system" in `dashboard/src/style.css`), so a person
on a light system gets a light page and gets the dark one by changing the system setting; the page
is usable and legible in both themes and only the choice inside the page was missing. Also noted:
the toggle code landed 9 minutes before this record, so no red state existed before the fix; the
`theme-toggle` entry in `e2e/known-failures.ts` served as the red. The asset stays.
